# Backend Development Project - Tutoriaal Practice Project

I am Vipul Mittal, B.Tech CSE Student from BML Munjal University, currently in 2nd year.

This is my backend development practice project. I worked on this project while learning backend development through the YouTube tutorial **Intro to Backend Development** by freeCodeCamp.

The main aim of making this project was to understand how a backend works, how a server communicates with a database, and how we can perform different operations using APIs.

## What I learned and worked on

While working on this project, I explored the following concepts:

- Setting up a backend project using Node.js
- Creating a server using Express.js
- Connecting the project to MongoDB
- Working with Mongoose models and schemas
- Understanding routes and controllers
- User registration and login
- Password hashing using bcrypt
- Performing CRUD operations (Create, Read, Update and Delete)
- Testing API requests using Postman

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- bcrypt
- dotenv
- Postman

## Getting Started

To run this project on your local system:

**1. Clone the repository**

```bash
git clone <your-repository-link>
```

**2. Open the project folder**

```bash
cd intro-to-backend-main
```

**3. Install the required packages**

```bash
npm install
```

**4. Set up environment variables**

Create a `.env` file and add your MongoDB connection URL.

**5. Start the server**

```bash
npm run dev
```
